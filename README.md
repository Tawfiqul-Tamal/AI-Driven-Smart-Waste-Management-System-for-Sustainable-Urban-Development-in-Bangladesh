# AI-Driven Smart Waste Management System for Sustainable Urban Development in Bangladesh

## Dataset Description

This repository contains the dataset used in the study:

**"AI-Driven Smart Waste Management System for Sustainable Urban Development in Bangladesh"**

The dataset was collected through a structured questionnaire survey conducted among 143 participants from different demographic backgrounds in Bangladesh.

## Contents

- Survey dataset (.xlsx)
- Supporting files related to data analysis
- Documentation for the research dataset

## Variables Included

The dataset contains information related to:

- Age group
- Gender
- Occupation
- Household size
- Daily household waste generation
- Type of waste generated
- Waste segregation practices
- Awareness of smart waste management technologies
- Support for AI-powered smart bins
- Attitudes toward sustainable waste management

## Data Collection Method

Data were collected using a structured questionnaire survey. Participation was voluntary, and respondents provided informed consent before completing the survey.

## Ethical Statement

All methods used in this study were carried out in accordance with relevant guidelines and regulations. The survey was anonymous, voluntary, and did not collect personally identifiable information.

## Data Availability

The dataset used and analyzed during the current study is publicly available in this repository to support transparency and reproducibility of the research findings.

This repository serves as the public data repository for the research study on AI-driven smart waste management and sustainable urban development in Bangladesh.
